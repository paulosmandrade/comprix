FastAPI

FastAPI é um framework web moderno e rápido (alta performace) para construção de APIs com Python, baseado nas anotações de tipo padrão do Python.

Principais características¶

  • Rápido

    Alta performance, equivalente a NodeJS e Go, graças ao Starlette e ao Pydantic. Um dos frameworks Python mais rápidos disponíveis.

  • Rápido para codar

    Aumenta a velocidade de desenvolvimento de recursos entre 200% e 300%.1

  • Poucos bugs

    Reduz cerca de 40% dos erros induzidos por humanos (desenvolvedores).1

  • Intuitivo

    Grande suporte a editores, com autocompletar em todos os lugares. Menos tempo depurando.

  • Fácil

    Projetado para ser fácil de aprender e usar. Menos tempo lendo documentação.

  • Enxuto

    Minimiza a duplicação de código: várias funcionalidades a partir de cada declaração de parâmetro. Menos bugs.

  • Robusto

    Código pronto para produção, com documentação interativa automática.

  • Baseado em padrões

    Totalmente compatível com os padrões abertos para APIs: OpenAPI (antigo Swagger) e JSON Schema.

Fonte

Características extraídas da documentação oficial do FastAPI.

A forma de instalar esse framework em nossa aplicação python e utilizando o comando abaixo.

poetry install
poetry add "fastapi[standard]"

pip install "fastapi[standard]"

uv pip install "fastapi[standard]"

Toda a biblioteca que adicionamos em nosso projeto, ela fica documentada no nosso arquivo raiz chamado pyproject.toml. No campo dependencies (nome e versão).

FastAPI
[project]
name = "comprix"
version = "0.1.0"
description = ""
authors = [
    {name = "paulosmandrade",email = "paulo.smandrade@hotmail.com"}
]
readme = "README.md"
requires-python = ">=3.14"
dependencies = [
    "fastapi[standard] (>=0.142.2,<0.143.0)"
]
