# Instalando o FastAPI
=== "Poetry"
    ``` poetry
    poetry install
    poetry add "fastapi[standard]"
    ```

=== "pip"

    ``` pip
    pip install "fastapi[standard]"
    ```

=== "uv"

    ``` uv
    uv pip install "fastapi[standard]"
    ```

Agora já temos o nosso ambiente preparado, para começar a codar os códigos.
